# 한국어 회차 품질 수직 슬라이스 설계

## 목표

`oh-story-claudecode`의 장편 집필 계약과 다중 감수 관점을 Jippeel의 기존 `/ai/generate` 흐름에 선택적으로 흡수한다. 첫 단계에서는 생성 요청 단위의 회차 브리프와 적응형 한국어 프롬프트를 도입하고, 기존 SSE·SQLite·사람 검수 계약은 유지한다.

## 범위

- `EpisodeBrief`는 요청에 포함되는 선택적 구조체다. 첫 단계에는 DB 마이그레이션을 하지 않는다.
- 브리프는 감정 목표, 핵심 사건, 인물 선택·대가, 금지사항, 다음 화 훅, 장면 유형, 선택 분량 목표를 표현한다.
- 브리프가 없으면 기존 요청이 동일하게 동작한다.
- 대사 비율·문단 길이·첫 500자 사건은 절대 규칙이 아니라 장면별 신호와 지침으로 바꾼다.
- 감수 프롬프트는 구조·인물·설정·문장·플랫폼 관점을 포함하되 기존 `[감수]`/`[수정본]` SSE 분할을 유지한다.
- 수정본은 자동으로 원고에 반영하지 않는다.

## 비범위

- 외부 패키지·hooks·agents·browser-cdp·플랫폼 스크래핑 추가
- 중국어 프롬프트·중국 플랫폼 루브릭 복사
- review_runs 영속 이력과 배치 검수
- 자동 게시·자동 원고 교체·AI 탐지 회피

## 계약

`GenerateContext.brief`:

```json
{
  "emotion_goal": "굴욕을 뒤집는 통쾌함",
  "core_events": ["파문 통보", "흑요검의 첫 반응"],
  "character_choices": ["주인공은 복귀 대신 독자 노선을 택한다"],
  "cost": "세가 복귀 가능성을 포기한다",
  "prohibitions": ["흑요검의 정체를 완전히 밝히지 않는다"],
  "next_hook": "검집이 열리려는 순간 뒤에서 손목을 붙잡힌다",
  "scene_type": "대립",
  "target_chars_novelpia": 3000
}
```

필수 필드는 `emotion_goal`, `core_events`, `character_choices`, `cost`, `prohibitions`, `next_hook`이고 나머지는 선택이다. 배열은 비어 있지 않아야 하며, 개수와 문자열 길이는 Pydantic으로 제한한다.

## 품질·호환성 기준

- 기존 `GenerateContext` 플래그 기본값과 필드명은 변경하지 않는다.
- 기존 SSE 이벤트와 `start` 필드명은 유지한다. 신규 이벤트·필드는 add-only다.
- 기존 감수 스트림은 `[수정본]`이 청크 경계에 걸려도 계속 분리되어야 한다.
- 브리프는 시스템·사용자 메시지에 명시적인 경계로 주입하고, 모델이 브리프 밖의 독립 사건을 만들지 않도록 지시한다.
- 한국어 UI 라벨을 사용한다.
