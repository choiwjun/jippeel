# D03-2 좁은 사양 — 회차 재개 계약 (resume surface)

- 상위: [전체 실행 계획 §6.2](2026-09-13-project-wide-execution-plan.md) — "재개 계약: 미해결 감수/다음 장면에서 재개 시 목표 버전·원문 revision 표시"
- 선행: D01(목표 버전), D03-1(flow_stage + 전이 이벤트 앵커) — 둘 다 수용 완료
- 상태: 구현용 확정 (추천안 자율 결정 권한에 따라)

## 1. 목적

에디터를 다시 열었을 때 "어디서부터 이어쓰는가"를 한 번에 보여주는 읽기 전용 계약.
D03-1의 앵커(goal_version·manuscript_revision)를 소비해 **드리프트**를 표시한다.
쓰기 경로는 추가하지 않는다 — 재개 정보는 파생 데이터이며 새 상태를 만들지 않는다.

## 2. API

### `GET /chapters/{cid}/resume` → `ChapterResumeOut`

| 필드 | 의미 |
|------|------|
| `chapter_id`, `project_id` | 소유 계약 (D01 고정 키) |
| `flow_stage` | 현재 단계 (D03-1) |
| `last_event` | 마지막 전이 이벤트 또는 null (D03-1 재사용) |
| `current_goal_version` / `current_chapter_revision` | 현재 앵커 원본값 |
| `goal_changed_since_transition` | `last_event` 존재 + `current_goal_version != last_event.goal_version` |
| `manuscript_changed_since_transition` | `last_event` 존재 + `current_chapter_revision != last_event.manuscript_revision` |
| `pending_refine_runs` | `accepted=false`인 RefineRun 수 (미해결 감수 신호 — 거절/미적용 구분 불가는 기존 스키마 한계) |
| `next_scene` | `sort_order` 순 첫 `content_md`가 빈 장면 `{id, sort_order, title}` — 없으면 null. 장면이 없으면 null |
| `scene_count` | 회차 장면 수 (재개 위치 맥락) |

- 404: 회차 없음.
- **쓰기 없음**: 어떤 테이블도 변경하지 않는 순수 파생 읽기.
- `last_event`가 없으면(전이 이력 0) 두 drift 플래그는 모두 `false`.

## 3. 불변조건

- 목표 저장·전이·원고 저장 외에 새 유도 동작 없음(자동 판정 금지 — §6.3).
- 원문 CAS·snapshot·flush 계약 불변.
- `pending_refine_runs`는 `accepted` 필드만 사용 — RefineRun 스키마 변경 없음.
- `next_scene` 판정은 `content_md` 공백 여부만 — 장면 완료 개념을 새로 도입하지 않는다.

## 4. 프론트 (thin UI)

`ChapterFlowControl` 오른쪽에 재개 요약을 추가한다:
- `goal_changed_since_transition` → "목표 변경됨" 배지
- `manuscript_changed_since_transition` → "원고 변경됨" 배지
- `pending_refine_runs > 0` → "미해결 감수 N"
- `next_scene` → "다음 장면: {title || '무제'}"

조회는 `['chapter-resume', chapterId]` 키. 전이 성공 시 `chapter-flow`와 함께 invalidate.

## 5. 테스트 matrix

| 축 | 케이스 |
|----|--------|
| 기본 | 신규 회차 → planning, last_event null, drift false, pending 0, scene 없음 → next_scene null |
| 드리프트 | 전이 → 목표 저장(v2) → goal_changed=true; 원고 저장 → manuscript_changed=true; 둘 다 동시 |
| 이력 없음 | 전이 없는 회차에서 목표/원고 변경해도 drift false |
| 감수 | RefineRun 2건(accepted 1·미적용 1) → pending_refine_runs=1 |
| 장면 | 장면 3개(본문 있음·빈·빈) → next_scene=첫 빈 장면; 모두 채워짐 → null |
| 보존 | resume 호출이 어떤 행도 만들지 않음(events·snapshots·goal 불변) |
| 404 | 없는 회차 |
| frontend | fixture: 배지 표시 조합 + tripwire |

## 6. 경계

- 완결 분리·이관·근거 연결(목표 필드↔원문 링크)은 후속 D03 단위.
- 운영 DB·실제 provider·credential·게시는 승인 경계 유지.
