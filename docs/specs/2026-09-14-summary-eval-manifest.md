# 생성 기억 평가 manifest (D04 잔여 — 평가 manifest 확장)

2026-09-14 · 상태: 정의 완료. d04-2 smoke manifest를 전 종류·배치 검토로 확장.

## 목적

summary worker가 만드는 MemoryEntry draft는 작가 승인 전 컨텍스트에 들어가지
않는다. 이 manifest는 작가(또는 평가자)가 draft를 승인/폐기할 때 쓰는
판정 기준이다 — smoke의 1회성 표를 재사용 가능한 체크리스트로 일반화한다.

## 공통 항목 (전 종류)

| # | 항목 | 통과 기준 | 실패 시 |
|---|------|-----------|---------|
| M1 | 사실성 | 본문·원천에 없는 고유명사·사건·수치가 없다 | 폐기 |
| M2 | 커버리지 | 핵심 사건·인물 행동·설정 정보가 빠지지 않았다 | 폐기 후 수동 요약으로 대체 가능 |
| M3 | 언어 | 한국어, 간결, 소설체 아닌 정보 요약체 | 폐기 |
| M4 | provenance | `generated_by`·`job_id`·`prompt_version`·`model_snapshot` 존재 | 버그 보고 — 승인 금지 |
| M5 | 게이트 | `visibility=draft` — 승인 UI 경유 외 승격 없음 | 사고 보고 |
| M6 | 유용성 | "이걸 모르고 다음 화를 쓰면" 틀릴 정보가 담겼다 | 폐기(정보 가치 없음) |

## 종류별 항목

### summary (회차 요약)

| # | 항목 | 통과 기준 |
|---|------|-----------|
| S1 | 범위 | 해당 회차 1개만 다룬다 — 다른 회차 내용 혼입 없음 |
| S2 | 결말 지점 | 회차가 끝나는 상황(다음 화 진입점)이 드러난다 |

### arc_summary (아크 요약)

| # | 항목 | 통과 기준 |
|---|------|-----------|
| A1 | 구간 흐름 | 회차 나열이 아니라 구간 전체의 사건 흐름이다 |
| A2 | 원천 일치 | `provenance.arc_source_entry_ids`의 승인 회차 요약만 반영한다 |
| A3 | 복선 진행 | 구간 안 복선의 설치/진행/회수 상태가 요약에 있다 |

### volume_memory (권 기억)

| # | 항목 | 통과 기준 |
|---|------|-----------|
| V1 | 골격 | 권 전체를 관통하는 사건 골격·관계 변화만 — 세부 에피소드 배제 |
| V2 | 원천 일치 | `provenance.volume_source_entry_ids`의 승인 아크 요약만 반영한다 |
| V3 | 종료 상태 | 권이 끝나는 시점의 인물·복선 상태가 요약에 있다 |

## 배치 검토 절차

1. MemoryPage → 출처 필터 "자동 생성만" + 상태 "초안" → job이 만든 draft 대기열.
2. 항목별로 위 표를 대조 — 승인은 1건씩 명시 확인(일괄 승인 없음).
3. 폐기한 draft는 사유를 별도 메모/규칙 제안(E5)으로 남기면 반복 실패 패턴이
   개선 규칙이 된다.
4. 커버리지 선택과의 상호작용: 아크 승인 즉시 그 구간 회차 요약은 컨텍스트에서
   빠진다 — 아크를 승인하기 전에 하위 요약의 승인 상태를 먼저 확인할 것.

## 평가 기록 형식 (선택 — 인간 평가 세션용)

JSONL, 행당 1 판정:

```json
{"entry_id": 12, "kind": "arc_summary", "verdict": "approved",
 "failures": [], "evaluator": "human-1", "note": ""}
```

`failures`에는 실패한 manifest 코드(M1~V3)를 넣는다. 2인 평가 시 같은
entry_id의 두 행을 비교해 일치율을 낸다 — G02의 blind 평가와 같은 패턴.
