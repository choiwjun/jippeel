## 7. 최적 조합 (사용자 확정 방향)

```
[발상] SillyTavern (선택) → [작성/관리] 대시보드(원고·캐릭터·세계관) → [보조] AI 패널(모델 무관) → [윤문] im-not-ai
```

- 관리를 대시보드로 통합 (novelWriter·SillyTavern은 API 연동 단계에서 선택)
- AI는 OpenAI 호환 API면 무엇이든 (LM Studio/KoboldCpp/GPT/Grok/Claude)
- GPT·Grok은 한국어 품질 우수 (도구의 기본 프롬프트가 중·영어인 것만 커스터마이징 필요)
