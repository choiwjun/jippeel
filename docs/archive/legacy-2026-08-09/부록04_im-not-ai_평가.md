# 부록 04 — im-not-ai(Humanize KR) 스킬 평가

> 평가일: 2026-08-24 / 저장소: github.com/epoko77-ai/im-not-ai (⭐4,925 / fork 522 / MIT / 2026-08 활발 / imnotai.kr)

---

## 1. 개요

- **정체**: AI(ChatGPT·Claude·Gemini 등)가 쓴 한글을 "사람이 쓴 글처럼" 윤문하는 오케스트레이터 스킬 (v2.3.2)
- **라이선스**: MIT (무료·재사용 자유 / 상업 이용 가능)
- **지원 환경**: Claude Code / GitHub Copilot CLI / Codex CLI / Gemini CLI
- **설치 방식**:
  - 마켓플레이스 권장: `/plugin marketplace add epoko77-ai/im-not-ai` → `/plugin install humanize-korean@im-not-ai`
  - 클론: `git clone` → `./install.sh` (claude/codex 자동 감지 → 전역 심링크)

## 2. 기능

- **10대 카테고리 × 70개 패턴** (S1 결정적/S2 강함/S3 약함)으로 AI 티 탐지·수술적 수정:
  - A 번역투 ("~를 통해", "그/그녀" 강박, 이중 피동, 관계절 좌향 수식)
  - B 영어 인용·용어 과다 / C 구조적 패턴 (첫째·둘째·셋째, 불릿·이모지) / D 관용구 (결론적으로·시사하는 바가 크다)
  - E 리듬 균일성 / F 수식·중복 / G Hedging / H 접속사 남발 / I 형식명사 / J 시각 장식
- **4대 철칙**: ① 의미 불변 ② 근거 기반(탐지 span만 수정) ③ 장르 유지(소설은 소설로) ④ 과윤문 금지(변경률 30% 경고·50% 강제 중단)
- **비용 최적화**: route_hint 3경로 — light(1콜) / standard(2콜, 1만자급 단일 윤문) / heavy(3+콜, 1.5만자 초과·검증 필요 시)

## 3. 우리 프로젝트와의 연결점

- "다듬기가 핵심 노동" 단계를 자동화 → 대시보드 파이프라인에 "AI 티 제거 윤문" 단계로 통합 가능
- 한국어 번역투 특화 (영어 humanizer 부재 영역)
- 장르 유지 철칙 → 웹소설 문체 보존
- 내용 불변 → 작가의 창작물 주권 보존

## 4. 판정

- **평가: ✅ 필요하며 가치 있음. 설치 권장.** (품질 향상 용도)
- **설치 상태: ✅ 설치 완료 (2026-08-25)**
  - 위치: `~/.agents/im-not-ai` (저장소) → `~/.agents/skills/{humanize-korean,humanize,humanize-redo}` 심링크
  - prime-agent에서 자동 발견 확인. 실측 검증 통과(진단→윤문→게이트 파이프라인 정상)

## 5. ⚠️ 규정·윤리 주의 (중요)

- 이 스킬의 이름("im-not-ai")과 마케팅에는 **AI 탐지 회피** 의도가 있음
- 플랫폼 규정과 충돌 가능:
  - 문피아: **일반 연재 본문·표지까지 AI 금지** — AI 생성+감추기는 규정 위반
  - 노벨피아: 공모전 금지 / 순수 창작 원칙
  - 조아라: 미확인
- 리스크: 들키면 별점 테러·연재 중단·공모전 당선 취소
- **권장 용도**: AI 사용 사실을 숨기는 도구가 아니라 **초안 품질을 자연스럽게 다듬는 보조 도구**로 사용 (AI 사용 여부는 플랫폼 정책·작가 판단에 따라 공개/비공개는 사용자 선택 사항이나, 규정 준수 방향 권장)
