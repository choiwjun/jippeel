## 3. 라이선스 준수 선언

- goink(AGPL-3.0): 소스 코드·주석·프롬프트 원문을 일절 열람하지 않고 README 기술 문서만 참고했다.
  구현(injection.py)은 자체 설계이며 알고리즘 개념(키워드 매칭 기반 검색)은 일반적 기법이다.
- NarraLume(Apache-2.0): 코드 복사 없음, 로드맵 개념 참고만.
- oh-story(MIT): 프리셋 문안은 동작·목적만 참고해 전면 재작성했다. 원문 복사본 없음.

## 4. 임베딩 업그레이드 경로 (v1 → v2 설계 메모)

```
injection.select_lore_for_text (현재 v1: title/keywords 부분일치 점수)
  ↓ v2 후보 설계
1) 임베딩: bge-small-zh-v1.5 대신 한국어 특화 모델 검토(예: BAAI/bge-m3 또는
   Korean-SBERT 계열) → ONNX int8 양자화로 로컬 추론
2) 인덱스: sqlite-vec 가상 테이블(lore_entries_vec), 회차 저장 시 백그라운드 증분 색인
3) 리랭킹: 벡터 상위 20 → MMR(λ=0.7)로 중복 제거 → 상위 K 주입
4) 하이브리드: FTS5 키워드 점수(v1) + 벡터 점수 가중 합산 — 고유명사는 v1이 강점
5) 게이트: 임베딩 모델 파일(~30MB) 선택적 다운로드, 미설치 시 v1로 폴백(fts.py의
   "선택 적용" 패턴과 동일)
```
