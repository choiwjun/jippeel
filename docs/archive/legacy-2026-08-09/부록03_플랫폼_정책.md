## 3. 플랫폼별 수익 상세

### 노벨피아 (조회수당 정산 — 공식 정책)
- PLUS 비독점 4원 / PLUS 독점 8·11·13원 / 독점 완결 10원 (2024.12.30 개정 기준)
- 인증 기준: 본인인증 + 50초 이상 열람 + 작가 본인·중복 디바이스 제외
- 3.3% 원천징수 + 결제수수료 공제
- 정산 총액 풀: 1,000억 상향 (2025 공지)
- PLUS 신청 조건: 자유연재 15편 이상(프롤로그 제외) + 편당 공백 제외 3,000자 이상 + 정산정보 등록

### 문피아
- 유료 회차 판매 매출 기반 정산 + 매니지 계약 원고료 (비율·조건 비공개)
- 무료 단계: 골드 후원금만 (분기별 현금 지급 신청 가능)
- '나 혼자서 유료화' 자가 신청 시스템 / 계약제안(무료 작품 설정 시 출판사·CP 컨택)

### 조아라
- 노블레스: 편당 용량별 정산금 × 정산조회수 (5~10KB 6원 / 10KB+ 12원), 30초 이상 열람 기준
- 프리미엄: 월 매출의 55%
- 후원쿠폰: 1장당 70원
- 최소 출금 3만원, 매월 6~15일 신청 → 20일 입금

## 4. 종합 순위 (신인 관점) — 확정

| 순위 | 플랫폼 | 이유 |
|:---:|--------|------|
| 🥇 | **노벨피아** | 첫 수익 가장 빠름 (PLUS 문턱 낮음 + 조회수 정산 + 신작랭킹) |
| 🥈 | **문피아** | 최대 무대·최다 기회 (단, 조건 비공개·무료 단계 수익 없음·AI 전면 금지) |
| 🥉 | **조아라** | 진입 최저 (무심사) / 여성향·로맨스·BL 적합, 수익 최소 |

## 5. 실전 권장

1. 빠른 데뷔+수익 경험 → 노벨피아: 자유연재 → 15편+3,000자 → PLUS → 조회수 정산 + 신작 챌린지
2. 장기 성장·웹툰화 → 문피아: 무료 연재 인내 + 문피아 아카데미(무료) + 지상최대 공모전
3. 여성향·로맨스·BL → 조아라 (또는 노벨피아 병행)
4. 사용자 전략: **노벨피아 + 문피아 병행** — 무료 연재 병행, 유료 전환 시 독점 조항 확인 후 단일 선택
