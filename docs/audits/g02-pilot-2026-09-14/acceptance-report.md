## 실제 발견 사항

1. **blind-04 병렬 스티칭 결함(실재)** — 장면 경계에서 소품·무기 상태·진입 동작 모순
   (`예비 배터리도 없었다` vs `여분 배터리 하나` 등). 단, 같은 출력의 review 레그가
   이 결함들을 위치 인용으로 전부 식별했다 — **파이프라인의 감수 표면이 설계대로
   동작함을 실증**. 운영 함의: parallel 초안은 review 반영 전 반제품 취급이 타당.
2. **blind-06 감수 정확도 최상** — 실제 원고의 `열 살 전`(회귀 10년과 모순)을 정확히
   포착해 `십 년 전`으로 수정 제안, 수정본(8,055자)에 자기 지적 전부 적용
   (`십 년 전` 1회·`열 살 전` 0회·트럭 통일 4회·`차가 자신을` 0회).
3. **수집기 갭 2건** — (a) review surface가 `refined` 채널을 blind 파일에 포함하지
   않았음 → provider-events.jsonl에서 복원해 blind-06.txt 갱신 완료.
   (b) `[감수]`·`서도윤` 기계 게이트 2건은 계측 한계로 판정 정정.
4. **인프라 1건** — case-05 review 레그 `RemoteProtocolError`(브릿지 끊김, draft는 완결).
